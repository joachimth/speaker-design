# speaker-design

#Mål:
Automatisk speaker design software.
Indlæs datablade, og lad softwaren udtrække al relevant information og forslå hvilken type kabinet de bedst passer i. Der tages højde for baffelstep, on og off axis respons og dæmpning i kabinettet.

Der bliver lavet frekvenskurver, tegninger af kabinet og spinorama simuleringer og plots.
