# Roadmap

## v0.1 — Foundation (current)
- Project scaffold (Vite + React + TS + Tailwind)
- TypeScript types + IndexedDB storage
- PDF datasheet extraction (T/S params + frequency curves)
- Pre-loaded driver database (4 drivers from mk2 repo)
- Driver manager UI

## v0.2 — Cabinet Design
- Thiele-Small calculations (sealed, ported, TL)
- Cabinet type auto-recommendation
- 3D cabinet visualization (Three.js)
- Baffle step + edge diffraction
- STL export

## v0.3 — Acoustic Simulation
- Crossover designer (LR4, BW4, etc.)
- Combined system response
- Directivity estimation
- Spinorama calculation + plots
- Vertical lobing / polar maps

## v0.4 — Advanced
- Multi-way system designer (2/3/4-way)
- Push-push configuration
- Waveguide designer (OS profile)
- Crossover optimization
- DSP export (MiniDSP, biquads)

## v0.5 — Polish
- Responsive design
- Dark mode
- Web workers for performance
- Project save/load/export
- Print views

## v1.0 — Production
- Full test coverage
- Documentation complete
- Docker image published
- GitHub Pages live
